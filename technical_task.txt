1. Техническое задание (ТЗ)
1. Наименование: Плагин для VS Code «CodeWrapper» (Умная обертка кода).
2. Цель разработки: Создание расширения для среды разработки Visual Studio Code, автоматизирующего процесс оборачивания выделенного фрагмента кода в базовые управляющие конструкции (if, for, while) с сохранением исходного форматирования.
3. Функциональные требования:
Интеграция в IDE: 
Плагин должен регистрировать команду в палитре команд VS Code и добавлять пункт в контекстное меню (по правому клику).


Условия активации: 
Команда должна быть доступна только при наличии выделенного текста в активном редакторе (editorHasSelection).



Пользовательский интерфейс:
При вызове команды должно появляться окно выбора типа конструкции (if, for, while).

После выбора типа должно появляться поле ввода для условия (для if/while) или заголовка (для for).



Логика обработки кода:
Плагин должен анализировать текущий отступ (количество табов или пробелов) выделенного блока.

Плагин должен добавлять один уровень вложенности (таб или настроенное количество пробелов) к выделенному коду.

Пустые строки не должны заполняться отступами (для чистоты кода).

Новые строки (необходимая конструкция и закрывающая скобка) должна устанавливаться на уровне базового отступа выделенного кода.



Обработка ошибок: 
При отсутствии выделения или отмене ввода пользователем плагин должен корректно завершать работу без внесения изменений в код.
